# Hi, I'm Abdulla Aziz 👋

I build AI-powered apps — mostly around Kurdish language technology and student productivity tools.

## What I'm working on

- 🌐 **[kurdlingoo](https://github.com/Abdulla090/kurdlingoo)** — Open-source Kurdish language learning platform with AI lessons, conversation roleplay, and gamified vocabulary
- 📚 **[aiacademic](https://github.com/Abdulla090/aiacademic)** — Academic AI webapp: citation generator, flashcard maker, quiz builder, summarizer, and more
- 🎤 **[zheer-voice](https://github.com/Abdulla090/zheer-voice)** — Kurdish voice interface
- 🩺 **[nestro-health](https://github.com/Abdulla090/nestro-health)** — Health-focused app built with React & TypeScript
